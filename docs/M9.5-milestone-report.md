# Milestone M9.5: Structured Discovery

Status: Complete

M9.5 extends Discovery with bounded static facts, a read-only Live Browser
pass, stable Fact IDs, UI/API correlation, separated static/live/correlation
timings, and explicit budget blockers. The existing Discovery 2.1 top-level
`observations`, `candidates`, and `scenario_observations` output remains
compatible; structured facts are carried as observation elements.

Todo facts include create/update/delete/search/summary/count endpoints, PATCH
and CORS behavior, required and max-length validation, priority enum values,
and the Search control/API correlation.

Acceptance:

- `npm run verify:m9:structured-discovery` - 16 passed, 0 failed
- Live discovery does not create, update, or delete Todo data.
- Cross-Origin requests are blocked by `BrowserNetworkGuard`.
- Static/live budgets produce explicit Blocker output.
- Repeated discovery produces stable Fact IDs.
