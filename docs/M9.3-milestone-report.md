# Milestone M9.3: Unified Plan Runner

Status: Complete

M9.3 adds `PlaywrightPlanRunner`, the execution layer for the declarative `autopw.test-plan/1.0` contract. It supports UI, API and Hybrid cases; shared variables and response bindings; Setup/Test/Cleanup phases; per-step results; case-scoped evidence; Playwright Trace; retry-to-Flaky reporting; and Product/Test/Infrastructure defect classification.

`PlaywrightFixtureRunner` now extends the unified runner through the M2 compatibility adapter. The default Core engine remains Fixture-driven until the later Planner/Compiler closed-loop milestone.

Acceptance:

- `npm run verify:m9:runner`
- `npm run verify:m9:plan-contract`
- `npm run verify:m9:storage`
- `node tools/verify-m2.mjs`
